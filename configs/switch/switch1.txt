! ============================================
! Switch1 - Infrastructure Lab
! VLAN, ports d'accès et trunk vers Switch0
! ============================================
!
! VLAN (visibles via "show vlan brief")
!   VLAN 10 : ADMIN / VLAN 20 : USERS / VLAN 30 : SERVERS
!
! Raccordements
!   Fa0/1 : trunk vers Switch0 (Fa0/5)
!   Fa0/2 : PC5 (ADMIN)
!   Fa0/3 : PC6 (USERS)
!
! Autres ports non configurés (VLAN 1)
! ============================================
!
no ip domain-lookup
!
vlan 10
 name ADMIN
vlan 20
 name USERS
vlan 30
 name SERVERS
!
interface FastEthernet0/1
 description TRUNK vers Switch0
 switchport mode trunk
!
interface FastEthernet0/2
 description PC5 - ADMIN
 switchport access vlan 10
 switchport mode access
!
interface FastEthernet0/3
 description PC6 - USERS
 switchport access vlan 20
 switchport mode access
!
end
